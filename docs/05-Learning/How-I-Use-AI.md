# How I Use AI on This Project

> [!important] Why this exists
> This project is on my resume. I must own every decision and every line. This policy keeps me honest, and it's a good thing to talk about in interviews.

## AI may
- Explain a concept (then **I** write the concept note).
- Review **my** code, design or ADR and point out problems.
- Help me debug after I've tried for at least 20–30 minutes myself.
- Generate boilerplate I already understand (config files, test fixtures).

## AI may not
- Make an architecture decision for me.
- Write the PRD, ADR decisions or concept notes.
- Write core logic (matching, scoring, locking, the state machine) before I've written my own version.
