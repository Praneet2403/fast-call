## How this vault works
1. **Plan:** pick tasks from [[Board]] into the current sprint.
2. **Design before code:** anything non-trivial gets a design doc (template: `Design-Doc`) or an ADR (template: `ADR`).
3. **Build and learn:** every new concept gets a note in `05-Learning/Concepts`, written in *your* words.
4. **Log daily:** one daily note per working day in `06-Journal` (what I did, what I learned, what blocked me).
5. **Prove it:** every performance claim gets a benchmark note in `07-Evidence`. No number goes on the resume without one.
